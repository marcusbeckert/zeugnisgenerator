# Zeugnisgenerator – GitHub Pages

Diese Version ist eine einzelne `index.html`, ohne API, ohne externe Bibliotheken und ohne Kosten.

## Veröffentlichung
1. In GitHub das Repository `zeugnis` öffnen.
2. Die vorhandene `index.html` durch die neue `index.html` ersetzen (Upload files / Commit changes).
3. GitHub Pages veröffentlicht die Seite unter `https://beckertmarcus.github.io/zeugnis/`.
4. Gegebenenfalls die Seite mit neuem Browser-Tab öffnen oder den Browser-Cache aktualisieren.

## Wichtig vor dem Wechsel
Vorher im bisherigen Generator die Bausteinsammlung als JSON exportieren. Die neue Version übernimmt vorhandene Browserdaten soweit möglich. In jedem Themenbereich und Zeitraum werden **genau sechs Standardbausteine** angezeigt; bisherige zusätzliche Bausteine werden separat als eigene Bausteine erhalten.

## Hinweise
- Die Halbjahresauswahl zeigt je sechs verschiedene Starttexte.
- Eigene Bereiche erscheinen zwischen Welterkundung und Besondere Teilnahme / Stärken.
- Jeder neue Bereich bekommt sechs Standardbausteine je Zeitraum.
- Zusätzliche eigene Bausteine werden separat angezeigt, damit die Zahl der Standardbausteine stets sechs bleibt.
- Bitte personenbezogene Daten und JSON-Exporte geschützt aufbewahren.
- Diese Datei wurde syntaktisch geprüft, aber nicht auf einem echten iPad getestet.
