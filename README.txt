ZEUGNISGENERATOR – GitHub-Version mit genau 6 Startbausteinen

1. Diese Version verwendet einen neuen lokalen Speicherbereich. Daher beginnen alle 11 Standard-Themenbereiche mit genau 6 Textbausteinen in Allgemein, 1. Halbjahr und 2. Halbjahr.
2. Jeder Textbaustein kann einzeln bearbeitet oder dauerhaft gelöscht werden. Weitere Bausteine lassen sich ergänzen.
3. Frühere eigene Bausteinsammlungen können per JSON-Import wiederhergestellt werden. Achtung: Ein Import übernimmt auch die dort gespeicherte Anzahl, die von 6 abweichen kann.
4. Vor Änderungen an einer vorhandenen Sammlung empfiehlt sich ein JSON-Export.

Die Datei benötigt weder API-Schlüssel noch zusätzliche Bibliotheken.
